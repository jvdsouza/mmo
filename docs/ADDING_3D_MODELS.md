## Quick Start - Get Models in 5 Minutes

### Option 1: Kenney Assets (Easiest)

**Best for:** Quick testing, simple style

```bash
# 1. Download
# Visit: https://kenney.nl/assets/platformer-kit
# Click "Download" (free, no account needed)

# 2. Extract and move
unzip platformerkit.zip
cp platformerkit/Models/GLTF/*.glb client/assets/models/characters/

# 3. Open Godot
cd client
godot project.godot

# 4. Drag .glb into FileSystem panel
# Done! Model is imported with animations.
```

### Option 2: Quaternius (Best Free Quality)

**Best for:** Production-quality characters, lots of options

```bash
# 1. Visit https://quaternius.com/packs.html
```

**Best for:** Professional quality, huge animation library

```bash
# Requires free Adobe account

# 1. Go to https://www.mixamo.com
# 2. Sign in

#    - Idle

```

#### Converting FBX to GLB (Blender Method)

```bash
# Install Blender (free): https://www.blender.org/download/

# 1. Open Blender
# 2. File → Import → FBX (.fbx)
# 3. Select your Mixamo character
# 4. File → Export → glTF 2.0 (.glb)
# 5. Check "Apply Modifiers"
# 6. Check "Animation"
# 7. Export

# Or use online converter:
# https://products.aspose.app/3d/conversion/fbx-to-glb
```

## Godot Import Process

### Step 1: Create Assets Folder Structure

```bash
cd client
mkdir -p assets/models/characters
mkdir -p assets/models/monsters
mkdir -p assets/models/environment
```

### Step 2: Import .glb File

**Method A: Drag and Drop (Easiest)**
1. Open Godot project
2. Open FileSystem panel (usually bottom-left)
3. Navigate to `res://assets/models/characters/`
4. Drag .glb file from your file explorer into Godot
5. Godot automatically imports it

**Method B: Copy Files**
```bash
cp /path/to/your/character.glb client/assets/models/characters/
# Godot will auto-detect on next launch
```

### Step 3: Verify Import

After import, you'll see:
```
assets/models/characters/
├── character.glb
└── character.glb.import  # Auto-generated by Godot
```

Click on `character.glb` in FileSystem:
- Preview appears in viewport
- Inspector shows import options
- Can see embedded animations

## Using Imported Model in Your Player Scene

### Step 1: Create Animated Player Scene

Replace the capsule with your model:

```
File: client/scenes/player_animated.tscn

Player (CharacterBody3D)
├── Model (imported .glb scene)  ← Drag character.glb here
│   ├── Armature (auto-imported)
│   ├── Mesh (auto-imported)
│   └── AnimationPlayer (auto-imported with animations)
├── AnimationTree (add this node)
├── CollisionShape3D
└── CameraPivot
    └── Camera3D
```

### Step 2: Add AnimationTree

1. Select your Player node
2. Add Child Node → AnimationTree
3. In Inspector for AnimationTree:
   - **Tree Root**: Create "AnimationNodeStateMachine"
   - **Anim Player**: Select the imported AnimationPlayer
   - **Active**: Check this

### Step 3: Configure State Machine

Click AnimationTree → Edit → State Machine:

**States to add:**
```
Idle → Walking → Running
  ↓
Attack → (returns to Idle)
  ↓
Hit → (returns to Idle)
  ↓
Death
```

**Add each animation:**
1. Right-click in state machine graph
2. "Add Animation"
3. Select animation from dropdown
4. Connect states with arrows

**Transitions:**
```
Idle → Walking: when speed > 0.1
Walking → Idle: when speed < 0.1
Walking → Running: when speed > 3.0
Running → Walking: when speed < 3.0

Any → Attack: on combat event
Attack → previous: auto (end of animation)

Any → Hit: when damage taken
Hit → previous: auto (end)

Any → Death: when health <= 0
```

### Step 4: Update Player Script

Modify `client/scripts/player.gd`:

```gdscript
extends CharacterBody3D

@export var entity_id: String = ""
@onready var animation_tree: AnimationTree = $AnimationTree
@onready var animation_state = animation_tree.get("parameters/playback")

var speed: float = 0.0

func _ready():
    # Register with combat system
    if CombatEventManager:
        CombatEventManager.register_entity(entity_id, self)

    # Start with idle
    animation_state.travel("Idle")

func _physics_process(delta):
    # Update speed for animation blending
    speed = velocity.length()

    # Update movement animations
    if speed < 0.1:
        animation_state.travel("Idle")
    elif speed < 3.0:
        animation_state.travel("Walking")
    else:
        animation_state.travel("Running")

# Called by CombatEventManager
func play_attack(anim_hint: String, target_pos: Vector3, event: Dictionary):
    # Face target
    if target_pos != Vector3.ZERO:
        look_at(target_pos, Vector3.UP)

    # Play attack animation
    animation_state.travel("Attack")

    # Return to idle after attack
    await get_tree().create_timer(0.8).timeout
    animation_state.travel("Idle")

func play_hit_reaction(damage: int, is_critical: bool):
    animation_state.travel("Hit")

    # Flash red
    flash_damage()

    await get_tree().create_timer(0.5).timeout
    animation_state.travel("Idle")

func play_death():
    animation_state.travel("Death")
    # Disable collision, fade out, etc.

func flash_damage():
    # Add damage flash effect
    pass
```

## Common Animation Names

Your imported .glb should have animations named:

**Locomotion:**
- `Idle` or `idle`
- `Walking` or `walk`
- `Running` or `run`

**Combat:**
- `Attack` or `attack_1`
- `Hit_Reaction` or `hit`
- `Death` or `die`

**If names don't match:**
1. Click AnimationPlayer in scene tree
2. View Animation list (bottom panel)
3. Rename animations:
   - Click animation
   - Rename in list
   - Update state machine references

## Troubleshooting

### Model appears black/no texture

```
Solution 1: Check materials
- Select model in scene
- Inspector → Material
- Ensure material is assigned

Solution 2: Re-import
- Click .glb in FileSystem
- Import tab → Reimport
```

### Animations not playing

```
Check:
1. AnimationTree is Active (checked in Inspector)
2. Anim Player is set to imported AnimationPlayer
3. State machine has animations added
4. Transitions are connected
```

### Model is tiny/huge

```
In .glb import settings:
- Scale: Adjust to 1.0 or as needed
- Reimport
```

### Model rotated wrong way

```
In .glb import settings:
- Root Rotation: Adjust Y rotation
- Or in player script: rotate_y(deg_to_rad(180))
```
